# Linh Anh Vietnamese Cuisine — concept website

Free showcase build #3 (Canada) — replacement for the Rob's showcase slot,
built Oct 24, 2026 under `captivating_web_design` + the house `design.md`.

**Direction:** "Hanoi night-market poster wall." Spine: a Ha Long night
market on Midland Avenue, stall by stall. Deliberately NOT Cactus's
grammar — different archetype, type (Be Vietnam Pro + Space Mono),
palette (pho broth / bone cream / broth gold / chili) and signature.

**Signature motion — THE POUR:** the hero is a 50-frame scroll-scrubbed
sequence (in `lib/frames/`) of broth being ladled into the bone-marrow
phở đặc biệt. At rest the bowl steams; scrolling works the ladle.
Lenis smooth scroll; reduced-motion gets a static hero.

**Facts:** 3290 Midland Ave Unit 1, Scarborough · (416) 332-8688 ·
open daily 11 AM–11 PM · 4.6★ / ~4,005 Google reviews ·
@linhanhvietnamesecuisine. Dishes from the restaurant's public
DoorDash categories; review quotes verbatim with sources in
`lib/data.ts`. Menu prices fill in from `research/material.md` —
never guessed.

**Imagery:** hero bowl, pour sequence, banh mi and spring rolls are
purpose-generated photoreal imagery made for this concept (Evans's
realism standard). The Stall Index photo bands lead with Linh Anh's
REAL plates — customer photos from their public Google/Yelp listings
plus shots from their own Instagram (@linhanhvietnamesecuisine).
No stock photos of other restaurants' food.

Run: `npm run build && npm start` (or import the repo in Vercel after
sign-off — nothing is pushed before Evans approves).
